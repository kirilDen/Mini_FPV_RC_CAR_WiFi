# KDen_Mini Rc Car
Realizing my childhood dream of creating a mini FPV RC car for indoor racing games!'

(Tires are printed from TPU for better traction)

https://youtube.com/shorts/G_jguQ4fAcw?si=hs_rlDZ7Hp37q1EM
